# Zetamac Speed Trainer (Mobile PWA)

Мобільний веб-додаток (Progressive Web App) для щоденного тренування швидкості ментальної арифметики за стандартом [Zetamac Arithmetic](https://arithmetic.zetamac.com/). Оптимізований для досягнення цільового нормативу **≥45 правильних відповідей за 120 секунд**.

## Технічні вимоги та ціль
* **Цільовий показник**: $\ge 45$ правильних відповідей за 120 секунд.
* **Необхідна середня швидкість**: $\le 2.67$ с на одне математичне рівняння.
* **Мобільний бар'єр**: Стандартна клавіатура iOS/Android створює затримку введення (input lag), зсув макета екрана та приховані перемикання розкладки.
* **Інженерне рішення**: Вбудований низьколатентний тактильний цифровий блок (Numpad) з підтримкою подій `pointerdown` / `touchstart` без 300ms delay, перемиканням розкладки (Phone 1-2-3 зверху або Calculator 7-8-9 зверху), синтезованим звуковим супроводом (Web Audio API) та вібро-відгуком (Navigator Vibration API).

## Математична логіка генерації (Zetamac Engine)

1. **Додавання ($+$)**:
   * Діапазон: $a \in [2, 100]$, $b \in [2, 100]$.
   * Відповідь: $a + b$.
2. **Віднімання ($−$)**:
   * Зворотне до додавання: обираються два доданки $a, b \in [2, 100]$, формується сума $s = a + b$.
   * Рівняння: $s - a = b$.
   * Гарантія: різниця завжди додатна ($b \ge 2$), зменшуване $\le 200$.
3. **Множення ($\times$)**:
   * Діапазон: $a \in [2, 12]$, $b \in [2, 100]$.
   * Порядок відображення: випадковий ($a \times b$ або $b \times a$).
   * Відповідь: $a \times b$.
4. **Ділення ($\div$)**:
   * Зворотне до множення: обираються множники $a \in [2, 12]$, $b \in [2, 100]$, формується добуток $p = a \times b$.
   * Рівняння: $p \div a = b$.
   * Гарантія: результат завжди ціле число без залишку.

### Алгоритмічна оцінка
* **Часова складність генерації**: $\mathcal{O}(1)$ псевдовипадкова генерація з фіксованими межами.
* **Часова складність валідації**: $\mathcal{O}(1)$ миттєве порівняння рядка введення з числовим значенням відповіді без натискання Enter.
* **Просторова складність**: $\mathcal{O}(N)$ пам'яті для історії з $N$ розв'язаних задач (обмежено останніми 100 сесіями в LocalStorage).

## Особливості інтерфейсу

* **Swiss White Minimalist Design**:
  * Чисте біле тло `#ffffff` (`bg-white`).
  * Поверхні `#fafafa` та `#f4f4f5`.
  * Тонкі межі `1px solid` (`border-zinc-200`).
  * Чорні монохромні акценти `#09090b`.
  * Моноширинний шрифт (`font-mono`) для таймера, формул та числових показників.
  * Нульовий візуальний шум (відсутність неонових градієнтів, 3D-ілюстрацій та емодзі-маркерів).
* **Live Pace Tracker**:
  * Проекція підсумкового результату в реальному часі на основі поточної швидкості: $\text{Pace} = \frac{\text{score}}{t} \times 120$.
  * Динамічний індикатор випередження / відставання від цілі 45.
* **Детальна аналітика після забігу**:
  * Статус досягнення цілі: `GOAL ACHIEVED (≥45)` або `BELOW TARGET`.
  * Розподіл швидкості за кожним окремим оператором ($+$, $-$, $\times$, $\div$).
  * Повний хронологічний журнал відповідей із часом вирішення кожної задачі.
* **Щоденний трекер**:
  * Автоматичний підрахунок серії тренувань (Streak).
  * Збереження особистого рекорду.
* **PWA Offline**:
  * Маніфест `manifest.webmanifest` для встановлення як автономного додатку («Додати на головний екран»).
  * Service Worker для повної працездатності без інтернет-з'єднання.

## Локальний запуск та збірка

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки
npm run dev

# Збірка оптимізованого production-бандла
npm run build

# Попередній перегляд production-збірки
npm run preview
```
